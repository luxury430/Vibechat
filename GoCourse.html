What Is Neurowave Lab?

A real-time 3D wave function visualizer. You type any mathematical equation in terms of x, y, and t, and the engine evaluates it across a 90×90 vertex grid every frame — producing a live animated surface. The height of each point equals z = f(x, y, t). Colors map low-to-high using a spectral palette (blue → violet → magenta).

Drag the surface to orbit. Scroll or pinch to zoom. The camera auto-rotates when idle.

Writing Equations

Type any math expression in the input bar. The engine compiles it instantly using mathjs.

Examplesin(d*3 - t*2) * cos(x*2 + y*2 + t)
Stochasticfbm(warpX(x,y,1.8), warpY(x,y,1.8), 3) * 3
Feedbacksin(x*2+t)*cos(y*2-t) + prev(x,y)*0.85
Audiob * sin(x*2+t) + m * cos(y*2-t)

A red border means a syntax error. Press Enter to apply.

Parameter Sliders

Spatial ωScales x and y before evaluation. Higher = smaller/denser waves (0.2 – 5.0)
Speed vMultiplies the time variable t. Negative = reverse time (−3 to +3)
Phase φConstant offset added to t before evaluation (0 to 2π)
Damp λRadial damping: multiplies z by e−rλ. Higher = stronger edge fade (0 – 2.5)

Control Buttons

▮▮ PauseFreeze time — the wave stops animating. Click again to resume.
↻ RandomLoad a random preset equation from the built-in library.
⚔ BattleEnter dual-equation mode. Two equations are summed together, creating superposition effects.
Fb: ON/OFFFeedback mode. Enables the prev(x,y) function to read the previous frame, creating echo and memory effects.
∇ FieldShow gradient vector field. Arrows display ∇z (the slope direction) at each sampled point.
Ripple: ONClick anywhere on the surface to emit a radial wave packet from that point.
Clear (n)Remove all active ripple emitters from the surface.
🎤 MicEnable microphone input. Feeds audio amplitude into variables a, b, m so your voice/music deforms the wave.
⇓ Export PNGCapture the current frame as a high-resolution PNG with equation, measurements, and timestamp overlay.
↻ CameraReset the camera to the default viewing angle and re-enable auto-rotation.

Additive Layers

Layers let you stack multiple equations on top of the primary wave. Each layer has:

CheckboxEnable or disable the layer without deleting it.
EquationAny valid expression using all the same variables and functions.
+ Addz = primary + layer (default mode, superposition)
× Mulz = primary × (1 + layer×0.3) — amplitude modulation
− Subz = primary − layer (destructive interference)
= Repz = blend(primary, layer, opacity) — smooth crossfade
Opacity sliderWeight of the layer contribution (0 = none, 2 = double-strength).

Tips & Tricks

01

Start with Spatial ω = 2–3 for denser wave patterns. Values below 0.5 produce very large slow-moving hills.

02

Use negative Speed v to reverse time — most wave equations look equally beautiful flowing backwards.

03

Combine fbm() with ripple emitters for a turbulent ocean effect: set base equation to fbm(x*0.5,y*0.5,5)*2, then place several ripples.

04

Feedback echoes grow unstable above prev(x,y)*0.95. Stay below 0.92 for stable patterns; exceed 1.0 intentionally for Feedback Singularity discoveries.

05

Enable Mic and speak or play music. Try a*sin(d*3-t*2)*3 to see your voice shape the entire surface.

06

Use Battle mode to create interference: enter sin(x*2+t) in the first field and cos(y*2-t) in the second to produce a classic standing wave grid.

07

The Export PNG embeds the live equation, peak/RMS measurements, and timestamp directly into the image — every export is fully annotated.
